# Requirements

- Git 2.30 or newer available on `PATH`.
- Windows PowerShell 5.1 or PowerShell 7.4 or newer.
- An existing Git working tree.
- Repository-local author configuration before committing.
- An existing upstream and non-interactive authentication before using
  `-Push`.
- Read and write access to every included path.

PSScriptAnalyzer 1.25.0 is used by contributors and CI, but is not a runtime
dependency. No At0mFlow account, API key or paid dependency is required.
